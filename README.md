# Aniki Visual Pack Creator
![Made for Playnite Fullscreen Themes](https://img.shields.io/badge/Made%20for-Playnite%20Fullscreen%20Themes-A600FF?style=for-the-badge)

</div>

**Aniki Visual Pack Creator** is a portable Windows app that makes it easy to create your own Visual Packs for **Aniki ReMake**.

Choose your images, position them directly in the preview, adjust the look if needed, and export everything as a ZIP ready to import into **Aniki Helper**.

## Download

Download the latest version from the **Releases** section of this repository.

No installation is required. Just download `AnikiVisualPackCreator.exe` and launch it.

> Windows SmartScreen may display a warning because the application is not digitally signed.

## Features

- Create a complete Visual Pack for Aniki ReMake.
- Handles all 14 images used by the Visual Pack system.
- Drag images directly into the app.
- Move images freely and use the mouse wheel to zoom.
- Adjust saturation, brightness, contrast and dark overlay.
- Automatically applies the Aniki image treatment where needed.
- Preview parts of the Aniki ReMake interface while positioning some images.
- Reuse the current image for any views that are still empty.
- Open and edit an existing Visual Pack.
- Save your work as an editable `.avpc` project and continue later.
- Export everything as a ZIP ready for Aniki Helper.
- Available in English, French and Spanish.
- Fully portable — no installation required.

## How to create a Visual Pack

1. Enter a name for your Visual Pack and your author name.
2. Choose a view from the list on the left.
3. Select an image or drag and drop one into the app.
4. Move and zoom the image until you are happy with the preview.
5. Adjust the image settings if needed.
6. Repeat for the other views.
7. Use **Fill empty views** if you want to reuse the current image for views that are still empty.
8. Click **Export Visual Pack ZIP** when your pack is ready.

## Import your Visual Pack

Once your ZIP has been exported:

1. Open **Aniki Helper**.
2. Go to the **Visual Packs** section.
3. Click **Import Visual Pack**.
4. Select the ZIP created by Aniki Visual Pack Creator.
5. Apply your new pack.

That's it — your custom Visual Pack is now ready to use in Aniki ReMake.

## Editing an existing pack

You can also open an existing Visual Pack folder.

If the images already use the filenames expected by Aniki ReMake, the Creator will load them into their corresponding views so you can edit and export the pack again.

## Image processing

Most Visual Pack images automatically receive the default Aniki image treatment during export.

`MainBackground.jpg` keeps its original colors.

The optional interface previews shown inside the Creator are only placement guides and are never included in the exported images. Special thanks to Ammz for the preview UI assets.
